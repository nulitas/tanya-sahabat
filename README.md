# TanyaSahabat (Frontend Interface)

> A virtual assistant web application allowing users to interact through a chat interface. It answers questions and saves conversation histories.

**Live Site:** [https://tanya-sahabat.vercel.app/](https://tanya-sahabat.vercel.app/)
**API Repo:** [TanyaSahabat API](https://github.com/nulitas/tanya-sahabat-api/)
**Demo Video:** [Watch Here](https://drive.google.com/file/d/1k3OCqK_uj-hchxEkp_jE9aVRDnOKyFOv/view?usp=sharing)

## ✨ Features
- Real-time chatting interface
- Save conversations directly to PDF
- Single-click to clear chat history
